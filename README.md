# House Price Data Cleaning and Analysis using Pandas

## Overview

This project demonstrates how Pandas can be used to import,
inspect, clean and analyze a house price dataset.

The project focuses on real-world data cleaning techniques
such as handling missing values, converting data types and
working with categorical variables.

## Concepts Used

- Importing CSV data
- Pandas DataFrame
- df.info()
- df.shape
- df.describe()
- Data type conversion
- Numeric conversion
- Category vs Object
- Missing value detection
- Missing value handling
- GroupBy analysis
- Exporting cleaned data

## Dataset Columns

- Area
- Bedrooms
- Bathrooms
- Doors
- Location
- Furnishing
- Price
